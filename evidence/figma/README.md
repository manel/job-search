# Figma index: Remuner and Abacum

Table of contents for all 30 Remuner and Abacum Figma files in Manel's Figma (his full file list, checked 2026-11-09): 28 distinct files indexed, one duplicate, and one other designer's file catalogued for completeness. Each file was extracted in full through the Desktop Bridge plugin: every page and every visible top-level node, with all text, annotations, components and image fills. Nothing was sampled. Three layers:

1. **This page:** what each file is and where to look.
2. **Per-file index** (linked below): every page with what it covers, notable content and the best image sources.
3. **Raw catalog** (`catalog/`): every frame on every page with a node link and its designer text. Search it when the index doesn't answer the question.

Cross-file outputs: [case-candidates.md](case-candidates.md) (what the files add to existing cases, and new case ideas). Local PNGs of the image sources are in `images/[file key]/`. The Dataset Manager story picks are in [../abacum-figma-index.md](../abacum-figma-index.md).

Page names start with the date as YYMM (`2302` = February 2023). Status markers: ✅ shipped or handed off, 🟡 not marked as shipped, 🔒 locked.

## Confidentiality

Many frames contain real customer names, employee emails, connector IDs and figures. They are fine for internal reference. Before any external use (portfolio, deck, PDF), replace or blur them.

## Re-running

Scripts are in [scripts/figma-index/](../../scripts/figma-index/). Keep only one or two Figma files open with the Desktop Bridge plugin. The plugin can only reach `localhost:9223-9232`, and the sandbox can't host the receiver, so Manel starts `recv.py` on 9232 himself. Then run `extract.js` per file; it posts one JSON per page. `render.py` builds the catalog and `digest.py` gives a condensed per-page reading view. Running 13 files in parallel froze Figma on 2026-11-09; don't.
