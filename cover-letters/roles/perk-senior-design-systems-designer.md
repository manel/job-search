Hello Perk team,

The Suitcase role asks for three things I have done on a production system: run a contribution model that keeps experimental components out of the core library, track adoption with engineering, and move product teams from one component set to another.

At Abacum I co-led the Abax design system with the head of design across five squads. Components moved from exploration into the canonical library only after review in a weekly sync. New ones shipped behind feature flags, and each squad added its own migration tickets to move off MUI, so squads ran their own rollout. Frontend engineers counted Abax against MUI component uses every month. When I left, Abax was at about 47% against an 80% target, with two squads through the form-element migration and a third partway.

At Remuner I was the only designer and built the system from scratch, starting with a small token set and ESLint rules that enforced use of system components. On the token pipeline I owned the design side, and used Codex to add CI validation, drift detection and smoke tests through PRs that engineers reviewed and merged. In the Figma files, I managed tokens through the Figma MCP with an AI agent.

Both systems are written up at manel-leiva.com/cases/design-systems.

Manel
