Hello Canonical team,

This role sits in a dedicated design system team and is measured on adoption, consistency and accessibility across products. That is the work I've done on two production systems, and the part I'd most like to keep doing.

At Remuner I was the only designer, so I built the design system from scratch and maintained it. I owned the token repo, used Codex to add CI validation and drift detection to it, and opened PRs that replaced hardcoded styles in the front-end app with tokens. With the Figma MCP and Claude I kept tokens in sync between code and Figma, checked that Figma components exposed the same options as the engineering components, and generated a Storybook view and written documentation for each one. I also brought the colours in use to WCAG AA contrast.

At Abacum I co-led the business case for Abax with the head of design, then worked on its token architecture, components and governance across five squads. When I left, Abax covered about 47% of component uses against an 80% goal. Designers rarely pushed back on the system. They forgot which components and variants existed, so I used detachment counts to find where a component wasn't being used and asked the designer why.

The design systems case is at manel-leiva.com/cases/design-systems.

Manel
