Hello Flodesk team,

The role asks for someone who has built a design system from scratch and changed one a running product depended on, with design output consumed as structured data. I have done both, and at my studio I designed and built modular content blocks so a client's managers could put together each product page themselves, which is close to what Studio blocks do for your members.

At Remuner I was the only designer and built the system from scratch, starting with a small token set and ESLint rules that enforced use of system components. On the token pipeline I owned the design side, and used Codex to add W3C token output, JSON output, CI validation and drift detection through PRs that engineers reviewed and merged. I also used the Figma MCP with an AI agent to keep tokens in sync with code and to write component documentation.

At Abacum I co-led the Abax design system with the head of design across five squads. I wrote the contribution guidelines and the naming and deprecation conventions, and ran the weekly library sync. Squads moved off MUI behind feature flags, and a monthly count put Abax at about 47% of component uses when I left, against an 80% target.

Both systems are written up at manel-leiva.com/cases/design-systems.
