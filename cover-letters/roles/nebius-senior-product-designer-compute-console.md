Hello Nebius team,

The Compute role covers the workflows technical teams use to create, configure, monitor and fix cloud resources. Most of my last four years went into that kind of problem in B2B software: configuration that used to need an engineer or a hand-edited file, turned into flows customers could finish on their own. I haven't designed a cloud console, so compute concepts are something I'd learn from your engineers.

At Abacum I led design and customer testing for Dataset Manager, which replaced hand-edited JSON configuration with guided steps for finance teams. In testing, people could write a transformation with Excel functions but not with SQL. I argued for extending Abacum's Excel-like modeling language instead, even though it was harder for Engineering to build. I also proposed moving dimension creation into the open dataset, so users stopped abandoning a half-finished configuration to create one somewhere else. The implementation team's read was that standard configuration took about half the time it used to.

At Remuner I was the only designer on a multi-module sales-compensation platform. That included the admin side, where customers activated modules and set roles, permissions and access levels. I built its component library and token system too, and later opened PRs that replaced hardcoded styles in the front end with tokens, which engineers reviewed and merged.

The Dataset Manager case is at manel-leiva.com/cases/dataset-manager.

Best,
Manel
