Hello Wizeline team,

This role caught my attention because its day-to-day focus is familiar: building components, maintaining Figma libraries, documenting how the system should be used, and working with engineers to keep design and code aligned.

At Abacum, I helped build and run a design system spanning five product squads. I worked on its Figma library, two-tier token architecture, component model, and pipeline from Figma through Style Dictionary to the frontend. I also ran the weekly library sync and contribution process and created the naming, issue-reporting, release, and migration practices that kept the system usable as it grew.

At Remuner, I was the sole designer and built the component library and token system from scratch alongside regular product work. I ran an ongoing audit to define missing states, variants, and behaviors with engineering. I later used Codex to add CI validation, drift detection, smoke tests, an HTML preview, and additional token outputs through PRs reviewed and merged by engineers.

The two systems were built in different environments, but both required the same discipline: make component decisions reusable, document them clearly, and give designers and engineers a shared source of truth they can maintain.
