## Reading order for a new session

1. This file (already done)
2. [applications/active.md](applications/active.md) — the action queue; the SessionStart hook also surfaces overdue `next_action_on` dates from the records
3. [memory.md](memory.md) — observations and rules captured during the search
4. [TODO.md](TODO.md) — open items; surface anything overdue or blocking
5. Task-specific file: `applications/records/[company-role].md` for a live process, [context/target-roles.md](context/target-roles.md) and [context/positioning.md](context/positioning.md) for strategy or a fit call, [context/salary.md](context/salary.md) before any salary figure, [evidence/experience-facts.md](evidence/experience-facts.md) before any experience claim, [context/portfolio.md](context/portfolio.md) for portfolio work, [context/linkedin.md](context/linkedin.md) for profile work, [interviews/prep.md](interviews/prep.md) plus `interviews/[company]/` for interview prep
6. [principles.md](principles.md) and [context/writing-rules.md](context/writing-rules.md) before any written output
