# Instructions for any assistant

Read `START_HERE.md` first. This repository is agent-agnostic: use its Markdown files and playbooks as the instructions, not vendor-specific commands. Do not assume this file is automatically loaded by every assistant.

Be factual and direct. Do not invent metrics, ownership, outcomes, salary bands, or current application status. Preserve approved copy unless the user asks to rewrite it. When evidence is missing, flag the gap.

For recruiter-facing writing, read `strategy/writing-rules.md`, the relevant strategy file, and `evidence/experience-facts.md`. For a role application, assess fit before drafting. For an existing process, update its application record only after an action or status change is confirmed.
